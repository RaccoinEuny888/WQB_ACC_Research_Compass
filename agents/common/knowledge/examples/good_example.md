# 好範例（教學用虛構卡）：指數調入公告後的被動資金壓力

> **這是教學用的虛構卡**，題材取自公開的教科書級文獻（指數納入效應），**未經任何實測**，不代表任何研究結論。
> 用途：示範一張合格的假說卡「長什麼樣」，給 Hypothesis Smith 照格式寫、給 Premise Reviewer 當評分參照。

## 為什麼它是好範例（閱讀重點）

1. **白話故事有具體的人、誘因、限制**：被動基金經理、追蹤誤差、宣布日到生效日的時間差。
2. **多空兩側分開判斷**，誠實標出哪一側只是對沖配平。
3. **核心論點附公開文獻**，並主動列出不利證據與「未確認」清單。
4. **第 3 柱明確定義 naive 版本**，說清楚自己多剝掉了什麼。
5. **生死線在跑之前就寫死**，含一組「機制若成立就該變弱」的反向證偽組。

## 白話情境

**市場不效率性**：指數調整的「被迫買盤」時間點和數量都是公開可預期的，但有人仍在生效前把股票賣給被動基金，而且價格在生效後會部分回吐。

**故事**：指數公司宣布某檔股票下個月納入。追蹤這個指數的被動基金經理被考核的是「追蹤誤差」，不是報酬——他寧可在生效日收盤價買貴一點，也不願提早買而偏離指數。於是大量買單集中在生效日收盤。套利者提前買進、在生效日賣給被動基金；生效後沒有新的被迫買家，價格回落。

**如何獲利**（多空明細）：
- 多：公告後、生效前的調入股；機制故事支撐？**有故事**（被迫買盤尚未發生）
- 空：生效後的調入股（壓力消失後回吐）；機制故事支撐？**有故事**（需求曲線向下傾斜，暫時性價格壓力退去）
- 訊號側判定：雙邊，但兩側在**不同時間段**
- 橫斷面檢查：只有被調整的股票受影響，逐股不同。✓

**實作注意**：
- 事件稀疏，同時持有的股票數很少，要注意集中度。
- 公告日與生效日要從可靠來源取得，不可用事後資料回填。

## 四柱檢驗

### 1. 核心論點 — ✅ PASS
被動基金受追蹤誤差考核，必須在特定時點、以特定數量買入，這是**制度造成的價格無關需求**。需求曲線若向下傾斜，就會產生可捕捉的暫時性價格壓力。
- 公開文獻：Shleifer (1986)、Harris & Gurel (1986) 記錄了納入效應與部分回吐。
- ⚠️ 不利證據：後續文獻指出納入效應在近年大幅縮小（套利者變多、公告到生效的時間差被利用）。
- ⚠️ 未確認：效應在不同指數、不同市場的大小差異。

### 2. 交易對手 — ✅ PASS
**生效日收盤買進的被動基金**。他們知道自己買貴了，但不修正，因為 mandate 要求最小化追蹤誤差，偏離指數的職業風險大於多付的成本。這是**成文制度限制**，不是無知。

### 3. 結構優勢 — ✅ PASS（有條件）
naive 版本＝「被納入的股票做多」。它混入兩種污染：(a) 被納入的公司通常剛經歷強勁上漲（動能）；(b) 公告當天的資訊效應（被選中本身被解讀為好消息）。
我們的分離：只取「公告後到生效前」的視窗，並對過去報酬做 `regression_neut`，剝掉動能；把公告當日排除，剝掉資訊效應。

### 4. 為何持續 — ⚠️ PASS（強度弱）
被動資產規模持續成長，被迫買盤的規模只會變大；mandate 不會因為有人套利而改變。
⚠️ 逆風：這是 1986 年就發表的效應，套利者早已進場，殘餘報酬可能很小。**本柱強度弱，是本卡最大風險**。

## 操作化方向

- 主訊號：公告後到生效前的事件旗標 × 預估被動需求（被動持股比例 × 指數權重變化 ÷ 日均成交量）。
- 剝離：對過去 252 天報酬做 `regression_neut`。
- 輸出：`group_neutralize(·, industry)`。

**生死線（預先承諾）**
- K1 **naive 對照**：剝離版不贏 naive 版 → 第 3 柱不成立。
- K2 **反向證偽組**：把同樣構造套到「調出且無被動賣壓的股票」（例如只是權重微調、被動需求接近零者）。機制若成立，這組**應該明顯變弱**；若一樣強或更強 → 機制歸因錯誤，rejected。
- K3 **形狀**：生效後應出現回吐；若生效後持續上漲 → 這不是暫時性壓力，是資訊效應，rejected。
- K4 **換戰場**：發現訊號的那批資料不能自我證明，另一個 region 同號才算重現。
