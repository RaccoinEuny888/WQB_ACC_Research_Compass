# 四關：一張假說卡要回答的四個問題

> 一張假說一張卡。四關是「這個假說為什麼可能是對的、怎麼知道它錯了」的四個問題。
> 占卜家寫；任一關寫不具體就**不建卡**。審判官審的是：理由說不說得通、是不是在自圓其說、欄位搭配合不合理、有沒有經濟意義。
> 每一句主張都帶證據標籤：`[L 文獻]` `[H 未測假說]` `[O 本機觀察]` `[R 使用者裁定]` `[? 未確認]`。

## 進場前：假說一句話

格式：「**誰**（哪一群人）在**什麼情境**下**系統性做錯什麼**，所以**做多／做空什麼**。」

- 例：「ESG 分數高、但負面新聞多的公司是在『言過其實』；相信分數的 ESG 基金持續買進，之後表現落後 → 做空。」
- 判讀原則：**把 dataset 名稱換掉，這句話對任何股票都成立 → 它沒有說任何事**（見 `vague_logic_patterns.md`）。

## 第 1 關：現象與機制

要回答：觀察到什麼規律？哪一群人、在什麼情境、為什麼系統性做錯？

- 合格：指出具體的行為偏差或制度限制，而且偏向哪一邊、為什麼不是另一邊。
- 不合格：「X 與未來報酬相關」（純統計）、「投資人過度反應」（萬用、無法證偽）、名詞堆疊。
- 「把現象換句話說」不算機制。「跌深會反彈」是現象；機制要寫成一條鏈：沒有基本面新聞的特異報酬 → 多半是訂單失衡的價格壓力 → 願意接單的人要求折價 → 幾天後壓力消退、價格回來 → 接單的人賺的是那段折價。`[L] 提升 Alpha 穩健性的四個問題`
- 自我檢查：
  1. 換掉 dataset 名稱，這段故事還成立嗎？成立＝太空泛。
  2. 多方和空方各自有故事，還是其中一側只是配平？（配平要誠實標出來）
  3. 這個錯誤會讓**不同股票錯得不一樣**嗎？整體市場層級的錯誤會被中性化剝掉，收不到錢。

## 第 2 關：對手與為何不修正

要回答：誰在另一邊虧錢？他們為什麼不修正？

- 合格：具體到投資人類型（職稱、mandate、基金類型），加上不修正的原因：成本、制度、mandate、職業風險、放空限制、行為根源。
- 對手不一定不理性，很多是「在買現在就成交」：基金被贖回被迫賣（fire sale）、機構退出某檔持股的集中賣壓、指數調整、風控到線砍倉——每一個都知道自己在付溢價，只是當下沒得選。能列出這種名單才算具體。`[L] 提升 Alpha 穩健性的四個問題`
- 不合格：「市場」「其他投資人」（泛稱）；對手明顯會立刻修正（便宜又明顯的錯誤早就被修了）。
- 出口檢查：對手的故事推得出訊號側（偏多／偏空／雙邊）嗎？

## 第 3 關：為何持續

要回答：套利限制是什麼？什麼情況下會消失？

- 合格：給出結構性理由：被動資金規模、mandate 不會改、資訊成本、放空成本、注意力有限且揭露頻率固定。
- 先承認「它已經被套利掉一大半」，再說剩下的為什麼難吃。常見三種：**交易成本**（毛利集中在低流動股，扣完成本剩不多，所以只吃慢的那段）、**胃納量與策略綁死**（你提供流動性，錢一大你自己就變成需求方）、**最賺的時候最沒錢加碼**（波動飆高時預期報酬最高，但正是提供流動性的資本被抽走的時候）。`[L] 提升 Alpha 穩健性的四個問題`
- 不合格：「因為歷史回測有效」（那是結果不是原因）；「資訊會逐漸反映」但說不出為什麼這條資訊比別的慢、慢多久。
- 誠實標強度：如果這一關很弱（例如 1986 年就發表的效應），寫出來，這通常是卡最大的風險。

## 第 4 關：證偽設計

要回答：怎麼知道它錯了？在寫 expression 之前就要定好。

4.1 **可反駁預測**：方向、形狀、強弱關係。「如果結果方向相反，我哪一句會被推翻？」說不出來＝無法證偽。
4.2 **失效條件**，分三格寫，審結果時才分得出「正常變弱」和「機制壞了」`[L] 提升 Alpha 穩健性的四個問題`：
   - 強：什麼環境下應該最強（例：波動剛拉起、資金正在撤出）。
   - 弱但正常：什麼環境下變弱是預期中的（例：平靜期，造市競爭把價差壓到沒東西賺），不用慌。
   - 真的壞掉：什麼特徵代表機制失效（例：太多人一起做、去槓桿踩踏，**高波動期也不賺反而大賠**）——跟平靜期變弱完全是兩回事。
4.3 **對照組**：
   - naive 版本：最直覺的做法是什麼？它混入什麼污染？我們多剝掉／多加上哪一步？
   - 反向證偽組：同一套構造套到「機制不該成立」的資料或子集，**機制若成立這組應該明顯變弱**。沒有反向證偽組的卡，偵測不了歸因錯誤（見 `examples/case_signal_but_wrong_attribution.md`）。
4.4 **量測設計**（把假說翻成可觀察的量，LLM 在這裡的角色是「Economic Idea → Template 轉換器」`[L] Template Design 的小提醒`）：
   - observable variable（量什麼）：本機 `data_fields_raw` 裡真的存在的欄位 id、型別（VECTOR 要先 `vec_*`）、coverage、alphaCount；為什麼這個欄位量的是機制說的那個量。
   - signal horizon（看多長）：機制作用的時間尺度 → 對應 lookback 與持有期；與 turnover 相容嗎？
   - transformation（怎麼轉）：level／change／spread／freshness；跟誰比（peer benchmark 或 historical benchmark）；先 ts 再 group 還是先 group 再 ts。
   - **channel 提議**（`alpha`｜`spc`｜`both`）：量的是 BRAIN 欄位 → alpha；量的是公開權威資料（filings、公告、價格）且方向能寫成機械規則 → spc（Systematic Predictions Challenge，LLM prompt 通道）；兩者皆可 → both。
   - **SPC 適合度**（channel 含 spc 時必寫，審判官會審；來源 `knowledge/spc/lessons/failure_patterns.md` #3、#4）：
     (a) 方向能否錨定在**單一權威、格式固定**的資料源？模型只定幅度、不定方向。要模型「自己綜合多篇新聞判斷」→ 不適合（#4）。
     (b) 證據會不會太稀疏？~50 檔的子清單裡預期多少檔有合格事件；填不滿清單 → 換 universe 切面（先篩出「有事件」的標的）或接受低覆蓋設計或只走 alpha（#3）。
     (c) universe 切面跟著假說走（sector／市值帶／事件窗／波動帶），Update Frequency 跟著訊號半衰期走。
4.5 **生死線**（門檻數字標 `[R]`，使用者裁定）：
   - K1 naive 對照：剝離版不贏 naive → 「多剝掉的那一步」不成立。
   - K2 反向證偽：反向組 ≥ 主構造 → 歸因錯誤，判處決。
   - K3 形狀：預測的形狀沒出現（例如該回吐卻續漲）→ 不是這個機制。
   - K4 換戰場：發現訊號的那批資料不能自我證明；另一個 region／dataset 同號才算重現。

## 占卜家的自檢（v2，2026-11-19 起）

占卜家不再替使用者擋卡。每張卡四關各打 1～10 分＋一句理由（寫在「# 自檢」段），總分（四關平均）寫進 frontmatter `confidence`，由使用者決定要不要往下。

| 情況 | 處置 |
|---|---|
| 四關都具體、對照組寫得出來、欄位本機有 | 分數照實給，建卡 |
| 任一關寫不出具體的人／誘因／對手／可反駁預測 | 那關 ≤3 分、寫出「寫不出來的是什麼」，仍建卡 |
| 反向證偽組設計不出來 | 第 4 關 ≤3 分並明說「偵測不了歸因錯誤」，仍建卡 |
| 欄位本機沒有 | 4.4 標 `[?]`，提醒先同步或換 dataset，仍建卡 |
| 使用者明說放棄 | 不建卡 |

## 審判官審卡的清單

1. 四關逐關：讚美女神／懺悔後再審／處決。退回格式固定：「命中樣式 #N」＋「原句」＋「什麼情況下會錯」。
2. 自圓其說：循環論證（用結論當理由）、事後合理化（先有訊號再編故事）、換皮（把已知因子改個名字）。
3. 欄位搭配：卡上欄位本機真的有？欄位量的是機制說的那個量，還是只是名字像？
4. 經濟意義：把假說念給一個沒看過資料的人聽，他能說出誰、為什麼、虧給誰嗎？

## 狀態

`draft → self_checked →（可選：審判官）approved | conditional | needs_work | rejected`；之後 `expr_ready → simulating → expr_self_checked | expr_approved → template_approved → ga_running → validated | abandoned`。
- `self_checked`＝占卜家自檢過、還沒送審；`needs_work`＝審判官要求修改，但沒說機制錯。
- `rejected`＝審判官**明確判機制被證偽**，全域有效，查重時擋同機制新卡；只是寫得不具體不算。
- `abandoned`＝沒被證偽但現在做不了，**必寫復活條件**。
- 某戰場無訊號 ≠ rejected，只記在「戰場足跡」。

## 對照：舊版「四柱」

本機知識庫裡的範例寫於四柱時期。對照：核心論點 → 第 1 關；交易對手 → 第 2 關；為何持續 → 第 3 關；結構優勢（naive 版本多剝掉什麼）→ 第 4 關 4.3 與審判官的「換皮」檢查；凍結 → 已取消，改為版本紀錄。
